📋 FLUJOS IMPLEMENTADOS
─────────────────────────────────────────────────────────────────────

FLUJO 1: REGISTRO NUEVO USUARIO
  1. Usuario visita /registro
  2. Ingresa email, contraseña, selecciona roles
  3. API valida y envía código al email
  4. Usuario ingresa código en 10 minutos
  5. Cuenta se activa automáticamente
  6. Usuario puede hacer login
  7. Recibe token JWT + lista de rutas

FLUJO 2: ADMIN ASIGNA ROLES
  1. Admin visita /admin/usuarios
  2. Busca al usuario
  3. Selecciona rol del dropdown
  4. Hace clic en "Asignar"
  5. API valida y persiste cambio
  6. Usuario ahora ve nuevas rutas

FLUJO 3: LOGIN EXITOSO
  1. Usuario ingresa email y contraseña
  2. API verifica credenciales
  3. Obtiene roles y rutas del usuario
  4. Genera JWT con información completa
  5. Frontend recibe token y rutas
  6. Renderiza menú según permisos

🎓 ARQUITECTURA IMPLEMENTADA
─────────────────────────────────────────────────────────────────────

MVC + Clean Architecture + DIP (Dependency Inversion Principle)

CAPAS:
  1. Presentación (Blazor)
  2. API (ASP.NET Core)
  3. Lógica de Negocios (Services)
  4. Acceso a Datos (Repositories)
  5. Base de Datos (PostgreSQL/MySQL/SQL Server)

PRINCIPIOS SOLID:
  ✅ SRP: Cada clase una responsabilidad
  ✅ OCP: Abierto a extensión, cerrado a modificación
  ✅ LSP: Sustitución de Liskov respetada
  ✅ ISP: Segregación de interfaces
  ✅ DIP: Inversión de dependencias
